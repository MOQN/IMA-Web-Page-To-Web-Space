Firebase task list

Add, finish, or delete tasks. Changes appear in other windows too.

Get started

  1. Create a Realtime Database in Firebase Console.
  2. Set firebaseConfig in script.js to your app settings.
  3. Open the page with VS Code Live Server. Database rules must allow reads and writes.

Data is saved at classroom/tasks/taskID. For a real app, add login and rules that limit access.
